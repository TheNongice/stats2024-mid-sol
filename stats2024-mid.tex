\begin{problembox}{Problem 5}
According to the following code, what is the probability that the speed is 100?

\begin{lstlisting}
import random
speed = 50
if random.randint(0,2): # uniform discrete from 0 to 2
    speed = speed*2
if random.random() > 1: # uniform continuous from 0 to 1
    speed = speed*2
print(speed)
\end{lstlisting}

\begin{choices}
\item 25\%
\item 33\%
\item 50\%
\item 67\%
\end{choices}
\end{problembox}

\begin{solutionbox}
  เมื่อเราอ่าน Code ที่ปรากฏข้างต้นเราจะทราบว่ามีเพียง If-block แรกทำงานเท่านั้น เพราะ If-block ที่ 2 เป็นการสุ่มค่าในลักษณะของ continuous ที่เป็นไปได้ตั้งแต่ $[0.0, 1.0]$ 
  ซึ่งการที่ If-block ที่ 2 ทำงานได้นั้นค่าต้อง > 1 \underline{\textbf{ซึ่งไม่มีทางเกิดขึ้นจริง}} \textbf{จึงไม่ต้องนำมาพิจารณา}
  ฉะนั้นจะมีเพียงแค่เหตุการณ์ที่สุ่มออกมาแล้วทำให้ \texttt{speed = 100} นั้นมีเพียง 2 เหตุการณ์จากทั้งหมด 3 นั่นคือ 1, 2
  ทำให้ทราบว่าความน่าจะเป็นที่จะเกิดเหตุการณ์ดังกล่าวคือ $\frac{2}{3} \approx 0.66\overline{6} \approx 67\%$

  ตอบ $\boxed{4)}$
\end{solutionbox}

100 students were asked to fill the following survey. 40\% answer “C++”, 20\% answer “Java”, and 10\% answer “Both”. How many students can code in at least one language?

  สามารถคำนวณได้โดยตรงนำยอดที่กรอกแต่ละแบบมาบวกได้โดยตรง ซึ่งคิดได้จาก $40+20+10 = 70$ คน

  \vspace{0.5cm}
  \textbf{(มีต่อหน้าถัดไป...)}

  \newpage
  \underline{\textbf{Solution-2}}

\begin{problembox}{Problem 7}
Consider the following Python code.
\begin{lstlisting}
s=1
for i in range(1,n):
  s=s*i
for i in range(1,k):
  s=s/i
print(s)
\end{lstlisting}
What does this code compute?
\begin{choices}
\item $_n P_k$
\item $_{n-1} P_{k-1}$
\item $_n P_{n-k}$
\item $_{n-1} P_{n-k}$
\end{choices}
\end{problembox}

\begin{solutionbox}
  ทำการวิเคราะห์ว่าจาก Python Code ที่ระบุข้างต้นทำงานได้อย่างไร โดยเริ่มต้นจาก...
  \begin{itemize}
    \item For-block แรกทำงานตั้งแต่ $[1, n-1]$ ทำให้เรามีค่าตัว $s$ อยู่ที่ $1 \times 2 \times ... \times (n-1) = (n-1)!$
    \item For-block ที่สองทำงานตั้งแต่ $[1, k-1]$ ทำให้เรามีค่าตัว $s$ อยู่ที่ $1 \times 2 \times ... \times (k-1) = (k-1)!$
    \item เมื่อเขียนเป็นรูปสมการคณิตจะได้ว่า $\frac{1 \times 2 \times ... \times (n-1)}{1 \times 2 \times ... \times (k-1)} = \frac{(n-1)!}{(k-1)!}$
  \end{itemize}
  
  Permutation ของ ${}_nP_k$ สามารถถูกคำนวณได้โดย $\frac{n!}{(n-k)!}$ ให้ทำการจัดรูปของสมการที่อยู่ในแต่ละ Choice เพื่อเทียบว่าตัวเลือกใดตรงกับ $\frac{(n-1)!}{(k-1)!}$ โดยทำได้ดังนี้

  \begin{substmt}
    \item ${}_nP_k = \frac{n!}{(n-k)!}$
    \item ${}_{n-1}P_{k-1} = \frac{(n-1)!}{((n-1)-(k-1))!} = \frac{(n-1)!}{(n-k)!}$
    \item ${}_nP_{n-k} = \frac{n!}{(n-(n-k))!} = \frac{n!}{k!}$
    \item ${}_{n-1}P_{n-k} = \frac{(n-1)!}{((n-1)-(n-k))!} = \frac{(n-1)!}{(-1+k)!} = \frac{(n-1)!}{(k-1)!} \qed$
  \end{substmt}

  \vspace{0.5cm}
  \textbf{(มีบอกคำแนะนำเพิ่มเติมหน้าถัดไป...)}
  \newpage

  เนื่องจากการจัดรูปเป็นวิธีที่ให้ผลถูกต้องที่สุดแต่อาจก่อให้เกิดความสับสนหรือทำช้ามาก ๆ เพื่อความรวดเร็วระหว่างการสอบ แนะนำแทนค่าสำหรับตัวแปร $n, k$ มีค่าห่างที่ห่างกัน ณ ที่นี้ขอสมมติค่าเป็น $n=8, k=5$ จากรูปสมการเศษส่วนด้านบนจึงได้ว่า $\frac{7!}{4!}$ ถัดไปทำการหาว่าตัวเลือกในข้อสอบใดมีค่าตรงกับเศษส่วนข้างต้น ซึ่งแทนที่ตัวเลขได้ดังนี้...
  \begin{substmt}
    \item ${}_nP_k = {}_8P_5 = \frac{8!}{3!}$
    \item ${}_{n-1}P_{k-1} = {}_7P_4 = \frac{7!}{3!}$
    \item ${}_nP_{n-k} = {}_8P_3 = \frac{8!}{5!}$
    \item ${}_{n-1}P_{n-k} = {}_7P_3 = \frac{7!}{4!}$
  \end{substmt}

  ตอบ $\boxed{4)}$
\end{solutionbox}

\begin{problembox}{Problem 8}
In September, 18 days are sunny, 14 days are rainy, and 5 days are neither sunny nor rainy. How many days in September are both sunny and rainy?

\begin{choices}
\item 3
\item 5
\item 7
\item 9
\end{choices}
\end{problembox}

\begin{solutionbox}
  \begin{flushleft}
  $\begin{aligned}
    \text{กำหนดให้ } n(A) &:= \text{จำนวนวันที่แดดจ้า} \\
    n(B) &:= \text{จำนวนวันที่ฝนตก}
  \end{aligned}$
  \end{flushleft}

  โดยโจทย์ระบุข้อมูลแต่ละส่วนดังนี้ $n(A) = 18, n(B) = 14, n((A \cup B)') = 5$ โจทย์ต้องการหา $n(A \cap B)$ สามารถหาได้โดยใช้หลักการ Inclusion-Exclusion Principle นั่นคือ 
  \begin{align*}
    n(A \cup B) = n(A)+n(B)-n(A \cap B)
  \end{align*}

  จากข้อมูลที่มีในปัจจุบันเมื่อทำการวาด Venn Diagram จะได้ว่า

  \begin{center}
  \begin{tikzpicture}
      % Universal set
      \draw (-4,-3) rectangle (4,3);
      \node at (-2.95,2.5) {$U=30$};

      % Set A background
      \fill[blue!20] (-1.2,0) circle (2);

      % Set B background
      \fill[red!20] (1.2,0) circle (2);

      % A ∩ B background
      \begin{scope}
          \clip (-1.2,0) circle (2);
          \fill[purple!40] (1.2,0) circle (2);
      \end{scope}

      % Set A border
      \draw (-1.2,0) circle (2);

      % Set B border
      \draw (1.2,0) circle (2);

      % Labels
      \node at (-1.5,1.5) {$A$};
      \node at (1.5,1.5) {$B$};

      % Elements in each region
      \node at (-2.0,0) {$18-x$};
      \node at (0,0) {$x$};
      \node at (2.0,0) {$14-x$};
      \node at (3.2,-2.2) {$5$};

  \end{tikzpicture}
  \end{center}

  จากการที่เราทราบค่าของ $n((A \cup B)')$ จึงทำให้ทราบค่า $n(A \cup B) = n(U) - n((A \cup B)') = 30-5 = 25$ จึงทำให้เราหา $n(A \cap B)$ ได้โดยคำนวณดังต่อไปนี้
  \begin{align*}
    n(A \cup B ) &= n(A)+n(B)-n(A \cap B) \\
        25       &=  18+14-n(A \cap B) \\
    n(A \cap B)  &=  32-25 \\
    n(A \cap B)  &=  7 \\
  \end{align*}
  ตอบ $\boxed{3)}$
\end{solutionbox}

\begin{problembox}{Problem 9}
How many integers from 1 to 1,000 are divisible by 4 but not divisible by 5?
 
\begin{choices}
\item 150
\item 200
\item 230
\item 400
\end{choices}
\end{problembox}

\begin{solutionbox}
  \begin{flushleft}
  $\begin{aligned}
    \text{กำหนดให้ } n(A) &:= \text{จำนวนตัวเลขที่หาร 4 ลงตัว} \\
    n(B) &:= \text{จำนวนตัวเลขที่หาร 5 ลงตัว}
  \end{aligned}$
  \end{flushleft}

  จากที่โจทย์ระบุ ทำให้ได้ข้อมูลแต่ละส่วนดังนี้ $n(A) = \lfloor \frac{1000}{4} \rfloor = 250, n(B) = \lfloor \frac{1000}{5} \rfloor = 200, n(A \cap B) = \lfloor \frac{1000}{lcm(4, 5)} \rfloor = 50$ โจทย์ต้องการหา $n(A \cap B')$ สามารถหาได้โดย...
  \begin{align*}
    n(A \cap B') &= n(A) - n(A \cap B) \\
                  &= 250 - 50 \\
                  &= 200 \\
  \end{align*}
  สาเหตุที่สามารถหาโดยใช้ $n(A) - n(A \cap B)$ ได้นั่นเพราะความหมายของ $n(A \cap B')$ คือเอาของที่มีใน A แต่ไม่มีใน B ซึ่งหากลองวาดภาพ Venn Diagram ก็จะพบว่าสามารถคำนวณได้ด้วยวิธีข้างต้น

  \begin{center}
  \begin{tikzpicture}
      % Universal set
      \draw (-4,-3) rectangle (4,3);
      \node at (-2.95,2.5) {$U=1000$};

      % Set A background
      \fill[blue!20] (-1.2,0) circle (2);

      % Set B background
      % \fill[red!20] (1.2,0) circle (2);

      % A ∩ B background
      \begin{scope}
          \clip (-1.2,0) circle (2);
          \fill[purple!40] (1.2,0) circle (2);
      \end{scope}

      % Set A border
      \draw (-1.2,0) circle (2);

      % Set B border
      \draw (1.2,0) circle (2);

      % Labels
      \node at (-1.5,1.5) {$A$};
      \node at (1.5,1.5) {$B$};

      % Elements in each region
      \node at (-2.0,0) {$250-50$};
      \node at (0,0) {$50$};
      \node at (2.0,0) {$200-50$};

  \end{tikzpicture}
  \end{center}

  ตอบ $\boxed{2)}$
\end{solutionbox}

\begin{problembox}{Problem 10}

\item 420

\begin{solutionbox}
  จากโจทย์ระบุว่า

    \item มีผู้ชาย 5 คน และผู้หญิง 3 คน
    \item ต้องการเลือกตำแหน่งโดยที่แต่ละคนมีได้มากสุด 1 ตำแหน่ง
    \item First vice president ต้องเป็นผู้หญิง และ Second vice president ต้องเป็นผู้ชาย 
  \end{itemize}
  
  ทำการหยิบเลือกบุคคลที่มีข้อจำกัดมากที่สุดก่อนนั่นคือ First/Second vice president และอีก 2 ตำแหน่งที่เหลือไม่ระบุเงื่อนไขแต่สามารถมีได้เพียงแค่คนเดียว ทำให้คำนวณได้ดังนี้...
  \begin{align*}
    \underset{\text{(เลือก $1^{st}$VP)}}{3} \times 
    \underset{\text{(เลือก $2^{nd}$VP})}{5} \times 
    \underset{\text{(เลือกคนเป็นประธาน)}}{6} \times 
    \underset{\text{(เลือกคนเป็นเลขา)}}{5}
    = 450 \text{ วิธี}
  \end{align*}

  สังเกตได้ว่าในช่วงแรก ๆ จะเลือก 2 ตำแหน่งที่มีข้อจำกัดมาก่อนจึงจัดวิธีได้ $3 \times 5$ ทำให้เราทราบว่ายังมีคนที่ยังรอเลือกอีก $8-1-1=6$ คน
  และอีก 2 ตำแหน่งถัดจากนี้ไม่มีข้อจำกัดใด ๆ ทำให้เราสามารถคำนวณต่อได้ด้วย $6 \times 5$ ซึ่งมาจาก 6 คนสุดท้ายในตำแหน่งที่ (3) 
  และตำแหน่งที่ (4) ที่เหลือเพียง $5$ คนเพราะว่าตำแหน่งที่ (3) ได้รับการเลือกเสร็จสิ้น

  ตอบ $\boxed{4)}$
\end{solutionbox}

\begin{problembox}{Problem 11}
There are 5 men and 5 women in a class. They want to select 4 students to attend a conference, which must consist of at least one man and at least one woman. How many ways can they select students to attend the conference?
 
\begin{choices}
\item 140
\item 200
\item 210
\item 700
\end{choices}
\end{problembox}

\begin{solutionbox}
  จากโจทย์ระบุว่า
  \begin{itemize}
    \item มีผู้ชาย 5 คน และผู้หญิง 5 คน
    \item มีคนต้องถูกเลือกไปประชุมทั้งสิ้น 4 คน
    \item ต้องการเลือกผู้ชายและผู้หญิงพร้อมกันอย่างน้อย 1 คนไปประชุม จัดได้กี่วิธี
  \end{itemize}
  ใช้หลักการลบแบบ Complement ซึ่งมีหลักดังต่อไปนี้
  \begin{align*}
    n(\text{กรณีที่สนใจ}) &= n(\text{วิธีจัดกรณีไม่มีข้อจำกัด}) - \sum_{k=1}^{n(\text{กรณีที่ผิด})} n(\text{กรณีที่ผิด}_k)
  \end{align*}

  ในที่นี้มีกรณีที่ผิดกฏอยู่ 2 แบบคือเลือกเพียงผู้ชายเท่านั้นกับเลือกเพียงผู้หญิงเท่านั้นซึ่งสามารถคำนวณได้ดังนี้

  \begin{align*}
    \text{กรณีเลือกโดยไม่มีข้อจำกัด} &= \binom{10}{4} = 210 \text{ วิธี} \\
    \text{กรณีเลือกแต่ผู้ชาย} &= \binom{5}{4} = 5 \text{ วิธี} \\
    \text{กรณีเลือกแต่ผู้หญิง} &= \binom{5}{4} = 5 \text{ วิธี} \\
  \end{align*}

  $\therefore n(\text{กรณีที่สนใจ}) = 210 - 5 - 5 = 200 \text{ วิธี}$

  ตอบ $\boxed{2)}$
\end{solutionbox}

\begin{problembox}{Problem 13}
The CU equestrian club has 12 members. 3 of them are first-year students, 4 are second-year students, and 5 are third-year students. If we randomly select 3 club members, what is the probability that they are all in the same year?
 
\begin{choices}

\item $1/20$
\item $3/11$

  \begin{itemize}

    \item เป็นนักเรียนปี 1 จำนวน 3 คน
    \item เป็นนักเรียนปี 2 จำนวน 4 คน

  $\therefore$ ความน่าจะเป็นจึงมีค่า = $\frac{15}{220} = \frac{3}{44}$

\begin{problembox}{Problem 14}
4 players are playing Among Us. Each player can vote for one other player (but cannot vote for him/herself). If every player votes randomly, what is the probability that there is a player who receives exactly 3 votes.
 
\begin{choices}
\item $1/81$
\item $1/27$
\item $4/27$
\item $4/81$
\end{choices}
\end{problembox}

\begin{solutionbox}
  จากโจทย์ระบุว่า
  \begin{itemize}
    \item มีผู้เล่นในเกม Among Us ทั้งสิ้น 4 คน
    \item แต่ละคนโหวตได้เพียงแค่ 1 คนเท่านั้น (โหวตตัวเองไม่ได้)
    \item หาความน่าจะเป็นที่ผู้เล่นคนหนึ่งถูกโหวต 3 ครั้งพอดี
  \end{itemize}

  จากข้อมูลที่ได้รับทำให้ทราบว่า $n(S) = 3^4 = 81$ การหาค่า $n(E)$ สามารถหาได้จากการนับจำนวน\textbf{วิธีการถูกโหวต}ของผู้เล่นหมายเลขนั้น ๆ ซึ่งคำนวณได้จาก
  \begin{align*}
    n(\text{โหวตแต่ผู้เล่น No.1}) &=
      \underset{\text{(ผู้เล่นคนที่ 1 เลือกได้)}}{3}
      \times
      \underset{\text{(ผู้เล่นที่เหลือเลือกได้)}}{1}
      = 3 \\
    &\vdots \qquad\qquad\qquad\qquad \vdots \\
    n(\text{โหวตแต่ผู้เล่น No.4}) &=
      \underset{\text{(ผู้เล่นคนที่ 4 เลือกได้)}}{3}
      \times
      \underset{\text{(ผู้เล่นที่เหลือเลือกได้)}}{1}
      = 3
  \end{align*}

  นำกรณีที่โหวตแต่ละผู้เล่นมารวมกันจะได้ $3 \times 4 \text{ (จำนวนผู้เล่นทั้งหมด)} = 12$ วิธี
  
  $\therefore$ ความน่าจะเป็นจึงมีค่า $\frac{12}{81} = \frac{4}{27}$

  ตอบ $\boxed{3)}$
\end{solutionbox}

\begin{problembox}{Problem 15}
There are 3 dice. Each one have an equal probability to land on each of its face.
\begin{itemize}
  \item The first die (singular form of dice) has 6 faces, with numbers 1, 2, 3, 4, 5, 6.
  \item The second die has 5 faces, with numbers 1, 2, 3, 4, 5.
  \item The third die has 4 faces, with numbers 1, 2, 3, 4.
\end{itemize}
Mint rolls these dice. What is the probability that the three shown numbers are all different?
 
\begin{choices}
\item $1/3$
\item $2/3$
\item $7/15$
\item $8/15$
\end{choices}
\end{problembox}

\begin{solutionbox}
  จากสิ่งที่โจทย์ระบุเราทราบว่าการออกแต่ละหน้าในแต่ละลูกเต๋ามีโอกาสที่เท่ากันเสมอ (กล่าวง่าย ๆ คือ ลูกเต๋าแต่ละลูกมีโอกาสออกแต่ละหน้าที่ $\frac{1}{6}, \frac{1}{5}, \frac{1}{4}$ ตามลำดับเสมอ) 
  จึงสามารถหา ${n(S)}$ ได้ว่า $4 \times 5 \times 6 = 120$ วิธีเพราะว่าแต่ละตัวที่คูณนั้นมาจากผลลัพธ์ที่ลูกเต๋าแต่ละลูกสามารถออกมาได้

  ส่วนถัดไปคือการหาค่า ${n(E)}$ สามารถหาได้โดยใช้ 2 มุมมองนั่นคือหยิบลูกเต๋าหมายเลข (1) มาคิดก่อน กับหยิบลูกเต๋าลูกเต๋าหมายเลขที่ติดข้อจำกัดมากที่สุดก่อนในที่นี้คือหมายเลข (3)

  \noindent\dotfill\quad$ *** $\quad\dotfill
  
  \underline{\smash{\textbf{มุมมองที่ 1}}}

  หากเราคำนวณโดยเริ่มจากหยิบลูกเต๋าหมายเลข (1) มาก่อนนั้น จะต้องพิจารณาถึงกรณีย่อย ๆ มากพอสมควร
  สำหรับการเฉลย Solution นี้จะใช้สัญลักษณ์ดังต่อไปนี้ (X, Y, Z) โดยที่หมายถึงหมายเลขหน้าลูกเต๋าของหมายเลข (1), (2), (3) ตามลำดับ
  ซึ่งสามารถที่่จะแบ่งกรณีออกได้ดังนี้...
  \begin{align*}
    \text{(6, 5, 1-4);} \quad &
    \underset{\text{ลูกเต๋า (1) เลือกได้}}{1} \times 
    \underset{\text{ลูกเต๋า (2) เลือกได้}}{1} \times 
    \underset{\text{ลูกเต๋า (3) เลือกได้}}{4}
    = 4 \text{ วิธี} \\[1ex]
    \text{(6, 1-4, 1-4);} \quad &
    \underset{\text{ลูกเต๋า (1) เลือกได้}}{1} \times 
    \underset{\text{ลูกเต๋า (2) เลือกได้}}{4} \times 
    \underset{\text{ลูกเต๋า (3) เลือกได้}}{3}
    = 12 \text{ วิธี} \\[1ex]
    \text{(5, 1-4, 1-4);} \quad &
    \underset{\text{ลูกเต๋า (1) เลือกได้}}{1} \times 
    \underset{\text{ลูกเต๋า (2) เลือกได้}}{4} \times 
    \underset{\text{ลูกเต๋า (3) เลือกได้}}{3}
    = 12 \text{ วิธี} \\[1ex]
    \text{(1-4, 5, 1-4);} \quad &
    \underset{\text{ลูกเต๋า (1) เลือกได้}}{4} \times 
    \underset{\text{ลูกเต๋า (2) เลือกได้}}{1} \times 
    \underset{\text{ลูกเต๋า (3) เลือกได้}}{3}
    = 12 \text{ วิธี} \\[1ex]
    \text{(1-4, 1-4, 1-4);} \quad &
    \underset{\text{ลูกเต๋า (1) เลือกได้}}{4} \times 
    \underset{\text{ลูกเต๋า (2) เลือกได้}}{3} \times 
    \underset{\text{ลูกเต๋า (3) เลือกได้}}{2}
    = 24 \text{ วิธี}
  \end{align*}
  โดยสรุปคือเราจะหยิบกรณีย่อยเพื่อแบ่งกรณีให้รัดกุมและครอบคลุมที่สุดเพื่อป้องกันปัญหา Overcounting (การนับซ้ำ) 
  โดยเราจะเลือกให้ลูกเต๋าหมายเลข (1) เลือกที่จะหยิบเลขใด ๆ ก็ได้แต่เพื่อความง่ายและลดความสับสน 
  จึงเลือกที่จะหยิบหมายเลขที่อนาคตจะก่อให้เกิดข้อจำกัดมากที่สุดไปยังน้อยที่สุดก่อน เพื่อให้สามารถตรวจสอบได้ง่ายมากขึ้น
  ฉะนั้นเมื่อนำแต่ละกรณีรวมกันจะได้ว่า $n(E) = 4+12+12+12+24=64$ วิธี

  \noindent\dotfill\quad$ *** $\quad\dotfill

  \underline{\smash{\textbf{มุมมองที่ 2}}}
  ให้เริ่มหยิบดูผลลัพธ์ที่สามารถออกได้ของลูกเต๋าที่มีข้อจำกัดมากที่สุดก่อน ในที่นี้คือลูกเต๋าหมายเลข (3), (2), (1) ตามลำดับ ซึ่งสามารถคำนวณวิธีได้ดังนี้
  \vspace{-5pt}
  \begin{align*}
    \underset{\text{ลูกเต๋า (3) ออกผลได้}}{4} \times 
    \underset{\text{ลูกเต๋า (2) ออกผลได้}}{4} \times 
    \underset{\text{ลูกเต๋า (1) ออกผลได้}}{4}
    = 4^3 = 64 \text{ วิธี}
  \end{align*}
  \vspace{-5pt}
  เหตุผลที่ลูกเต๋าแต่ละลูกออกได้เพียง 4 หมายเลขในทุกลูกเต๋านั้นเป็นเพราะว่า
  \begin{substmt}
    \item ลูกเต๋าหมายเลข (3): เลือกหมายเลขได้ $1 \sim 4$
    \item ลูกเต๋าหมายเลข (2): เลือกหมายเลขได้ $1 \sim 5$ แต่ต้องเอาออก 1 ตัวที่เคยถูกเลือกแล้ว ทำให้เลือกได้จริง $5-1=4$
    \item ลูกเต๋าหมายเลข (1): เลือกหมายเลขได้ $1 \sim 6$ แต่ต้องเอาออก 2 ตัวที่เคยถูกเลือกแล้ว ทำให้เลือกได้จริง $6-2=4$
  \end{substmt}

  เมื่อเราทราบค่า $n(E), n(S)$ แล้วจึงสามารถหาค่าความน่าจะเป็นได้ $\frac{64}{120} = \frac{8}{15}$

  ตอบ $\boxed{4)}$
\end{solutionbox}


\begin{problembox}{Problem 17}
  63\% of CEDT students pass both the midterm and final exams of statistics class. Among those who pass the midterm exam, 90\% of them also pass the final exam. What percentage of CEDT students pass the midterm exam?
  
  \begin{choices}
  \item 53\%
  \item 56.7\%
  \item 70\%
  \item 73\%
  \end{choices}
\end{problembox}

\begin{solutionbox}
  \begin{flushleft}
    $\begin{aligned}
      \text{กำหนดให้ } M &:= \text{นิสิตสอบผ่าน Midterm} \\
      F &:= \text{นิสิตสอบผ่าน Final}
    \end{aligned}$
  \end{flushleft}

  จากโจทย์ระบุว่า $P(F \cap M) = 0.63, P(F|M) = 0.9$ โจทย์ต้องการทราบ $P(M)$ โดยสามารถหาได้โดยใช้ Bayes Theorem ได้ดังนี้
  \begin{align*}
    P(F|M) &= \frac{P(M|F)P(F)}{P(M)} \\
    &= \frac{P(M \cap F)}{P(M)}
  \end{align*}
  ทำการแทนค่าตัวแปรต่าง ๆ และแก้สมการจึงจะได้ว่า
  \begin{align*}
      0.9  &= \frac{0.63}{P(M)} \\
      P(M) &= 0.7 \text{ (หรือ 70\%)}
  \end{align*}

  ตอบ $\boxed{3)}$
\end{solutionbox}

\begin{problembox}{Problem 19}
  Among all companies in the stock market, 20\% are large companies, 30\% are medium companies, and 50\% are small companies. Last year, the stock price of 80\% of large companies, 70\% of medium companies, and 30\% of small companies went up. In total, the stock price of what percentage of companies in the stock market went up last year?
  
  \begin{choices}
  \item 52\%
  \item 56\%
  \item 60\%
  \item 64\%
  \end{choices}
\end{problembox}

\newpage

\begin{solutionbox}

  \underline{{\textbf{Solution-1}}}: หลักการคูณอัตราส่วน (Ratio)

  จากโจทย์ที่กำหนด สมมติว่ามีบริษัทอยู่ทั้งสิ้น 100 แห่ง (เพราะค่าทุกอย่างอยู่ในรูปแบบร้อยละ) ซึ่งมีบริษัทขนาดใหญ่ 20 แห่ง บริษัทขนาดกลาง 30 แห่ง และบริษัทขนาดเล็ก 50 แห่ง
  จากนั้นคำนวณจำนวนบริษัทที่ราคาหุ้นเพิ่มขึ้นในแต่ละขนาด ได้ว่าดังนี้
  \begin{align*}
    n(\text{บริษัทขนาดใหญ่ที่หุ้นเพิ่มขึน}) &= 20(0.8) = 16 \text{ บริษัท} \\
    n(\text{บริษัทขนาดกลางที่หุ้นเพิ่มขึน}) &= 30(0.7) = 21 \text{ บริษัท} \\
    n(\text{บริษัทขนาดเล็กที่หุ้นเพิ่มขึน}) &= 50(0.3) = 15 \text{ บริษัท} \\
    \therefore n(\text{จำนวนบริษัทที่หุ้นเพิ่มขึ้น}) &= 16+21+15 = 52 \text{ บริษัท}
  \end{align*}
  \vspace{-0.9pt}
  จากบริษัททั้งหมด 100 แห่งเมื่อคิดเป็นร้อยละจะทำให้เราทราบยอดร้อยละของบริษัทที่มีหุ้นเพิ่มขึ้นดังนี้
  \begin{align*}
    \frac{\text{จำนวนบริษัทที่หุ้นเพิ่มขึ้น}}{\text{จำนวนบริษัททั้งหมด}}
    &= \frac{52}{100} = 52\% \qed
  \end{align*}

  \underline{{\textbf{Solution-2}}}: หลักการ Law of Total Probability \& Bayes Theorem
  \begin{flushleft}
    $\begin{aligned}
      \text{กำหนดให้ } L &:= \text{บริษัทขนาดใหญ่} &\qquad M &:= \text{บริษัทขนาดกลาง} \\
      S &:= \text{บริษัทขนาดเล็ก} &\qquad U &:= \text{หุ้นบริษัทเพิ่มขึ้น}
    \end{aligned}$
  \end{flushleft}
  โจทย์ต้องการทราบค่า $P(U)$ หาได้โดยใช้หลักการ Law of Total Probability ดังนี้
  \begin{align*}
    P(U)  &= P(U|L)P(L) + P(U|M)P(M) + P(U|S)P(S) \\
          &= 0.8(0.2) + 0.7(0.3) + 0.3(0.5) \\
          &= 0.52 \text{ (หรือ 52\%)}
  \end{align*}

  ตอบ $\boxed{1)}$
\end{solutionbox}

\groupctx{29--30}{Students in a particular university are either in the CEDT or CP program. 60\% of CEDT students and 30\% of CP students can write JavaScript. Overall, 48\% of students in this university can write JavaScript.}
 
\begin{problembox}{Problem 29}
If a student can write JavaScript, what is the probability that this student is in CEDT program?
 
\begin{choices}
\item $3/4$
\item $4/5$
\item $5/6$
\item $6/7$
\end{choices}
\end{problembox}

\newpage

\begin{solutionbox}
  \begin{flushleft}
  $\begin{aligned}
    \text{กำหนดให้ } A &:= \text{นิสิต CEDT} \\
    B &:= \text{นิสิต CP} \\
    J &:= \text{เขียน JavaScript ได้} \\
  \end{aligned}$
  \end{flushleft}

  จากโจทย์ระบุว่า $P(J) = 0.48, P(J|A) = 0.6, P(J|B) = 0.3$ สำหรับข้อนี้โจทย์ต้องการหา $P(A|J)$

  ใช้ทฤษฎีบทของ Bayes Theorem ในการหาค่าความน่าจะเป็นย้อนกลับจาก ซึ่งได้ว่า $P(A|J) = \frac{P(J|A)P(A)}{P(J)}$ แต่ตอนนี้เรายังไม่ทราบค่าของ $P(A)$ จึงยังทำให้หาค่าไม่ได้
  สำหรับโจทย์ข้อนี้วิธีหา $P(A)$ ที่ง่ายที่สุดคือหาจาก $P(J)$ โดยใช้หลักการของ Law of Total Probability ทำให้สามารถคำนวณออกมาได้ดังนี้
  \begin{align*}
    P(J) &= P(J|A)P(A) + P(J|B)P(B) \\
    0.48  &= 0.6x + 0.3(1-x) \\
    0.48  &= 0.6x + 0.3 - 0.3x \\
    0.3x  &= 0.18 \\
    x  &= \frac{0.18}{0.3} = 0.6
  \end{align*}

  โดยจากการแก้สมการข้างต้นนั้นได้แทนที่ $x = P(A)$ และ $P(B) = 1-x$ เพราะ $P(B)$ สามารถหาได้โดยการนำจำนวนยอดร้อยละทั้งหมดมาหักหับยอดความน่าจะเป็นของการเกิด $P(A)$ เมื่อรู้เช่นนั้นแล้วจึงแก้สมการออกมาและได้ผลลัพธ์ $P(A) = 0.6$ 

  เมื่อได้ค่า $P(A)$ แล้วจึงนำกลับมาแทนค่าในสมการของ Bayes Theorem ต่อดังนี้
  \begin{align*}
    P(A|J) &= \frac{P(J|A)P(A)}{P(J)} \\
          &= \frac{0.6 \times 0.6}{0.48} \\
          &= 0.75 \; (\text{หรือ $\frac{3}{4}$})
  \end{align*}

  ตอบ $\boxed{1)}$
\end{solutionbox}

\begin{problembox}{Problem 49}
Given $X \sim \text{Bernoulli}(0.3)$. Calculate $\text{Var}(X + X)$.
 
\begin{choices}
\item 0.21
\item 0.42
\item 0.63
\item 0.84
\end{choices}
\end{problembox}

\begin{solutionbox}
  จากสิ่งที่โจทย์ต้องการหาเมื่อใช้คุณสมบัติ Scaling and Shifting ที่กล่าวว่า...
  \begin{align*}
    Var(aX+b) &= a^2Var(X) \; \text{; (เมื่อ $a,b$ เป็นค่าคงที่ และ $X$ เป็นตัวแปรสุ่ม)}
  \end{align*}

  \begin{align*}
    Var(X + X) &= Var(2X) \\
               &= 2^2Var(X)
  \end{align*}
  
  ทำการหาค่า $Var(X)$ โดยการคำนวณจากสิ่งที่โจทย์กำหนดให้ โดยเราทราบว่าเป็น Bernoulli distribution และ $p=0.3$ โดยคำนวณได้จาก
  \begin{align*}
    Var(X) &= 0.3(1-0.3) \\
           &= 0.3(0.7) \\
           &= 0.21 \\
    Var(2X) &= 2^2Var(X) \\
            &= 4(0.21) \\
            &= 0.84
  \end{align*}

  ตอบ $\boxed{4)}$
\end{solutionbox}

\begin{problembox}{Problem 55}
Which statement best fits the memoryless property?
 
\begin{choices}
\item Students who have failed a course are as likely to fail the course the second time.
\item Somchai rolled no SSRs for the past 100 rolls. If the SSR chance is 1\%, he should get one SSR in the next 10 rolls.
\item A fair die has the same probability for all sides.
\item For the Thai government lottery, the previous last-two-digit winning number cannot be the same as the next last-two-digit winning number.
\end{choices}
\end{problembox}

\begin{solutionbox}
  Memoryless Property คือคุณสมบัติของค่าตัวแปรสุ่มหนึ่งที่สามารถ model ได้ด้วย Geometric distribution โดยที่มีค่าความน่าจะเป็นของอนาคตที่ไม่มีความเกี่ยวโยงกับความน่าจะเป็นในอดีต
  \begin{substmt}
    \item \textbf{ถูกต้อง:} สามารถ model ได้ด้วย Geometric distribution และ ผลลัพธ์ที่ได้จากในอดีตไม่ได้ส่งผลต่ออนาคต
    \item \textbf{ผิด:} ความน่าจะเป็นที่จะเกิดในอนาคตขึ้นอยู่กับผลลัพธ์จากอดีต
    \item \textbf{ผิด:} เพราะโอกาสการออกหน้าลูกเต๋ายุติธรรมนั้นมีค่าเสมอต้น-ปลาย เหมาะกับการใช้ Uniform distribution 
    ซึ่งขัดต่อคุณสมบัติของ Memoryless ที่ต้องเป็น Geometric distribution
    \item \textbf{ผิด:} ความน่าจะเป็นที่จะเกิดในอนาคตขึ้นอยู่กับผลลัพธ์จากอดีต
  \end{substmt}
  
  ตอบ $\boxed{1)}$
\end{solutionbox}
